# Web Development NC III – Set F: Countries (Candidate Resources)

| File / Folder | Contents |
|---|---|
| `countries.csv` | Data to import into your database |
| `flags/` | Images referenced in the CSV |
| `libraries/` | Bootstrap 5.3.3 and jQuery 3.7.1 (minified, offline) – optional. See `libraries/HOW TO USE.txt` |

## Getting the files
```
git clone https://github.com/vervanttechlab/SET-F.git
```
Copy the folder into your web server folder (e.g. `C:\xampp\htdocs\`).

There's **no internet** during the assessment. Use only the files in this repository.
